# 驭窗浮控

面向 Android 17（API 37）的独立悬浮快捷栏。收起时显示可拖动的小车图标，展开后可在应用快捷入口和媒体控制之间切换；也可通过控制中心磁贴开启或关闭悬浮窗。

## 功能

- 应用快捷入口：沟通、导航、音乐；应用图标来自系统，沟通入口支持启动主实例。
- 媒体控制：封面、下一首、播放/暂停、上一首，通过活跃媒体会话控制播放。
- 中央切换按钮带震动反馈；点击窗外或超时自动收起。
- 可调节展开模式、自动收起时间、悬浮窗大小（80%–160%）、背景透明度，以及运行时屏幕常亮。
- 原生快捷设置磁贴，可在应用内请求添加到控制中心。

## 安装与权限

从 [Releases](../../releases) 下载最新 APK。当前版本 `1.8.2`，最低及目标 API 均为 37。首次使用需要授予悬浮窗权限；媒体控制需要通知使用权。不同厂商的控制中心可能需要手动进入编辑页添加磁贴。

## 源码与构建

工程使用 Android SDK 命令行工具构建，未依赖 Gradle。`build.sh` 使用工作区相对路径，要求上级目录提供 `sdk/android-37.0/` 和个人签名证书 `experiment-signing.p12`；构建产物输出到工作区 `outputs/驭窗浮控/`。克隆到其他目录时，请按本地 SDK、签名证书和输出路径修改脚本。签名私钥不包含在仓库中；要覆盖安装已有 APK，必须使用与该 APK 相同的签名证书。

本仓库仅包含驭窗浮控工程，不包含先前用于研究的其他应用 APK 或设备日志。
