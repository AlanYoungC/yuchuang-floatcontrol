# 驭窗浮控

面向 Android 17（API 37）的轻量骑行悬浮助手。它把快捷应用、导航、媒体控制和运行状态集中在一个可贴边移动的界面里，适合需要快速确认和少打扰操作的移动场景。

## 主要功能

- **快捷应用**：沟通、导航、音乐入口可分别排序，图标优先使用系统应用图标。
- **媒体控制**：通过活跃媒体会话读取状态，支持封面、上一首、播放/暂停和下一首。
- **悬浮交互**：支持悬浮图标、常驻展开、自动收起、点击窗外收起和防误触保护。
- **位置与尺寸**：展开栏和收起图标共用贴边位置，可上下拖动，并可限制在左侧、右侧或两侧；悬浮窗和图标尺寸可以独立调节。
- **驾驶友好**：大尺寸控件、触觉反馈、即时状态刷新、可选屏幕常亮，减少骑行过程中寻找和确认按钮的时间。
- **控制中心**：提供原生快捷设置磁贴，用于快速启动或关闭悬浮窗。
- **诊断日志**：应用事件持续记录，可锁存点击前 15 分钟日志并继续采集；总占用限制为 500 MiB，并可通过 Shizuku 扩展到系统 logcat。
- **视觉样式**：支持跟随系统、浅色、深色、强光高对比和磨砂玻璃悬浮样式。

## 权限与使用

首次使用需要授予悬浮窗权限。媒体控制需要授予通知使用权；系统日志默认隐藏，连续点击设置页底部版本号 5 次后显示，可在其中启用或关闭。使用系统日志扩展时，需要安装、启动并授权 Shizuku。

不同厂商的控制中心可能需要手动进入编辑页添加“驭窗浮控”磁贴。

## 下载

从 [Releases](../../releases) 下载 APK。当前版本为 **1.8.8**，最低及目标 API 均为 37。

## 构建

工程使用 Gradle 9.5 与 Android Gradle Plugin 9.3.3。依赖通过 Google Maven 和 Maven Central 获取，发布构建会使用 CI 临时签名；本地构建可通过 `ANDROID_SIGNING_STORE`、`ANDROID_SIGNING_PASSWORD` 和 `ANDROID_SIGNING_ALIAS` 指定签名证书。

```bash
gradle --no-daemon assembleRelease
```

本地开发环境需要 Android API 37 SDK、JDK 17 和 Gradle 9.5。使用 `build.sh` 时，APK 会复制到工作区上级输出目录的 `outputs/驭窗浮控/驭窗浮控-1.8.8-API37.apk`。
