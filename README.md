# 驭窗浮控

面向 Android 17（API 37）的独立悬浮快捷栏。收起时显示可拖动的小车图标，展开后可在快捷应用和媒体控制之间切换；也可通过控制中心磁贴开启或关闭悬浮窗。

## 功能

- 快捷应用：沟通、导航、音乐；应用图标来自系统，沟通入口支持启动主实例。
- 媒体控制：封面、下一首、播放/暂停、上一首，通过活跃媒体会话控制播放。
- 中央切换按钮带震动反馈；支持常驻展开，也支持点击窗外或超时自动收起。
- 可调节展开模式、自动收起时间、展开悬浮窗大小（80%–160%）、收起图标大小（70%–160%）、背景透明度，以及运行时屏幕常亮。
- 应用分为总览、浮窗、内容、设置四页；总览显示运行与权限状态并提供悬浮窗总开关。媒体控件与快捷应用可分别排序，中间切换键固定；防误触范围以动态示意展示，运行时不增加额外覆盖层。
- 展开栏和收起图标共用贴边位置，均可上下拖动，并可限制在左侧、右侧或两侧。
- 原生快捷设置磁贴，可在应用内请求添加到控制中心。
- 诊断日志可锁存点击前 15 分钟并继续记录，支持 ZIP 导出，应用内日志总占用上限 500 MiB；可选通过 Shizuku 扩展到系统 logcat，内容可能涉及其他应用信息。
- JankStats 汇总主界面和展开浮窗的卡顿帧，系统 Trace 标记窗口切换与媒体命令；松手贴边使用 DynamicAnimation，点击与页面切换保持即时。

## 安装与权限

从 [Releases](../../releases) 下载最新 APK。当前版本 `1.9.16`，最低及目标 API 均为 37。首次使用需要授予悬浮窗权限；媒体控制需要通知使用权，系统日志默认隐藏，连续点击设置页底部版本号 5 次后显示，并需要安装、启动和授权 Shizuku。不同厂商的控制中心可能需要手动进入编辑页添加磁贴。

## 源码与构建

工程使用 Gradle 9.5 与 Android Gradle Plugin 9.3.3 构建。`build.sh` 使用工作区相对路径，要求上级目录提供 `tools/gradle-9.5.0/`、API 37 SDK、`deps/` 中的 Shizuku JAR 和个人签名证书 `experiment-signing.p12`；构建产物输出到工作区 `outputs/驭窗浮控/`。克隆到其他目录时，请按本地依赖与签名证书路径调整脚本及 Gradle 配置。签名私钥不包含在仓库中；要覆盖安装已有 APK，必须使用与该 APK 相同的签名证书。

本仓库仅包含驭窗浮控工程，不包含先前用于研究的其他应用 APK 或设备日志。
